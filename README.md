# Week 1 PDAC Knowledge Graph

## Overview
This project builds a simple Knowledge Graph (KG) from PDAC (Pancreatic Ductal Adenocarcinoma) related data using Python. It demonstrates how to extract relationships, structure them into a graph format, and perform basic analysis.

## Features
- Data preprocessing for PDAC datasets
- Entity and relationship extraction
- Knowledge graph construction
- Basic graph exploration and visualization

## Requirements
- Python 3.8+
- pandas
- networkx
- matplotlib (optional, for visualization)

Install dependencies:
```bash
pip install pandas networkx matplotlib
```

## Usage
Run the main script:

```bash
python week1_pdac_kg.py
```
